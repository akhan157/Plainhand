Plainhand's first release: a job-application assistant that runs on your own computer, uses your own AI subscription, and leaves every submit to you.

## Highlights

- **A profile in your own words.** Talk about your work; Plainhand saves what you say exactly as you said it, learns your voice from a few writing samples, and shows you how it sees you before trusting it.
- **One standard application.** A resume and cover letter you approve once, tailored for each role and revised in plain words ("make it shorter").
- **Accurate, not modest.** Every claim is traced to your evidence and graded undersold, balanced, stretched or unsupported. Titles, employers, dates and degrees are always exact.
- **Your format, no AI writing.** Every resume and cover letter is rendered in the layout read from your own resume PDF, and every draft goes through a humanizer pass that keeps facts and numbers.
- **Forms filled, you submit.** Checked live on Greenhouse, Lever and Ashby, with any-site mode for other employers. Your documents are uploaded and a pre-submit list shows what still needs you. LinkedIn and Indeed roles apply through the employer's link.
- **After applying.** Application records, follow-ups drafted from what you actually sent, outcome insights and discovery campaigns.
- **An assistant on Home**, on your Claude, ChatGPT or Antigravity account. It confirms every change, and a local MCP server lets your own agent use Plainhand.
- **Guided setup** on Home, Profile and Connections, plus light and dark themes.

## Install

You need Node.js 22+, a desktop session and one of the Claude, ChatGPT (Codex) or Antigravity command-line tools, signed in.

```bash
git clone https://github.com/akhan157/plainhand.git
cd plainhand
npm run setup
npm start
```

Then open http://127.0.0.1:3210. The full guide is in [docs/INSTALL.md](https://github.com/akhan157/plainhand/blob/main/docs/INSTALL.md), and the walkthrough is in [docs/USER-GUIDE.md](https://github.com/akhan157/plainhand/blob/main/docs/USER-GUIDE.md).

## Known limits

- The application browser needs a graphical desktop.
- PDF resume import needs Poppler (`pdftotext`). On Windows, paste your resume text instead.
- Workday and other account-based portals stop at sign-in for you to complete.
- Sign-in is through each provider's command-line tool. API keys aren't supported yet.

## Security

Local-only server with per-session keys and a strict content policy. The application browser is fenced off from your computer and home network, and it can't submit. See [SECURITY.md](https://github.com/akhan157/plainhand/blob/main/SECURITY.md).
