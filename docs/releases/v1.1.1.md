Plainhand 1.1.1 fixes three form-assistance bugs found by testing on live job postings, and adds installer checks on Windows and macOS.

## Fixes

- **Lever forms no longer stall on a captcha that isn't there.** Lever loads hidden hCaptcha frames on every application page. Plainhand treated them as a verification step, so form assistance stopped on every Lever job. Now only a captcha you can actually see counts as one, and a real one still pauses for you.
- **Cleaner field names on Lever.** The resume field was named "Resume/CV ATTACH RESUME/CV Couldn't auto-read resume. Analyzing resume... Success!" because Lever keeps status messages hidden inside the label. Hidden text is now left out.
- **Workday hands off at sign-in.** Workday shows its sign-in page a moment after you click Apply. Plainhand used to check too early and stop with "No supported navigation remains." It now waits for the page and tells you to sign in or create an account, which is where you take over.

Each fix has a regression test that fails on 1.1.0 and passes now.

## What was tested for this release

- The full local suite, including the Go dashboard, passed.
- The hosted Postgres workspace store ran against a real Postgres 17 database.
- The live workflow ran end to end with both Claude and ChatGPT (Codex), using a made-up candidate and a local test employer: evaluation, packet, PDF, approval, form filling with the PDF uploaded, and the handoff before submission.
- Plainhand's form reader opened live postings read-only, without typing or submitting anything. Greenhouse (Figma), Lever (Spotify, Palantir) and Ashby (Ramp, Linear) forms were read correctly. On Workday (NVIDIA, Salesforce), Plainhand reached the sign-in step and handed off there. Airbnb's Greenhouse posting redirects to Airbnb's own careers site, which Plainhand doesn't support, so it tells you to continue by hand.
- The one-line installers ran on GitHub's Windows and macOS machines. Each one installed Plainhand, passed `plainhand --check`, started the app and served the page. This closes the 1.1.0 note that the Windows installer had not been run.

## Limits

- Plainhand never submits an application, so no real submission was made.
- Workday applications need your own Workday account; Plainhand stops at the sign-in step.
- The application browser still needs a graphical desktop.
