Plainhand 1.1 is about making the first run feel like an app rather than a developer setup.

## Highlights

- **One command.** On macOS or Linux:
  ```sh
  curl -fsSL https://raw.githubusercontent.com/akhan157/Plainhand/main/install.sh | sh
  ```
  On Windows PowerShell:
  ```powershell
  irm https://raw.githubusercontent.com/akhan157/Plainhand/main/install.ps1 | iex
  ```
  It downloads Plainhand, installs Chromium, creates a `plainhand` launcher and starts it. The workspace defaults to `~/.plainhand/workspace` (`%USERPROFILE%\.plainhand\workspace` on Windows).
- **AI setup without the terminal.** Connections now does **Set up → Sign in → Check**. Plainhand downloads the Claude or ChatGPT connector into its own folder and opens the provider’s browser sign-in. Existing installations are reused; Antigravity still uses its official app.
- **Open from anywhere.** Workspace → Open from anywhere publishes a password-protected, read-only copy of the dashboard to the user’s own Vercel account. It can update while Plainhand runs, and it verifies the password gate even when the Vercel project has Vercel Authentication enabled.
- **A smaller repository.** Core modules, tests, benchmarks and dashboard tools now live in `lib/`, `tests/`, `benchmarks/` and `dashboard/node/`; the root file list dropped from 193 to 30.

## Fixes

- Dashboard builds without the optional `fonts/` folder and with `--data-root`.
- Tracker-relative `../reports/...` links resolve correctly.
- Only artifacts actually linked by the dashboard are uploaded.
- Insights band table no longer overflows at 1440 px.
- Ashby forms that render late are read correctly.
- Vercel account parsing and protected-deployment verification.
- Date-sensitive browser tests and the invariant benchmark fixture.
- Restored the fictional sample CV.

## Install limits

- The application browser needs a graphical desktop.
- PDF resume import needs `pdftotext`; pasting resume text still works.
- The AI connector download needs an internet connection and a provider subscription. The download path (including the connector's postinstall and a `--version` start check) was exercised with the global CLIs hidden; the provider's browser sign-in still needs the user's account.
- The Windows PowerShell installer was not executed in this release environment (no PowerShell available); the manual Windows install from a clone remains available.
- Remote view is read-only and contains the tracker, reports and `output/` files. It does not expose the Plainhand server or let anyone apply or submit.

## Security

The local server still binds only to `127.0.0.1`, uses a per-session key and a strict content policy, and the application browser cannot submit. Remote view uploads only a snapshot, with its own generated password and an optional Vercel account gate. See [SECURITY.md](https://github.com/akhan157/Plainhand/blob/main/SECURITY.md).
