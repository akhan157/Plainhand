Plainhand 1.1.2 fixes one more form bug found on a live careers site, and updates the README with a Job sites section and status badges.

## Fix

- **Embedded application forms open reliably.** Airbnb's careers site embeds a Greenhouse form that shows its Submit button before its fields. Plainhand took that for a review step and opened the application with no fields to fill. It now waits for the form to finish loading. In repeated runs on the live page it read all 19 fields every time. A regression test fails on 1.1.1 and passes now.

## README and docs

- Status badges for the test suite and for the Windows and macOS installer check.
- A **Job sites** section: what Plainhand does on Greenhouse, Lever and Ashby, on Workday, on a company's own careers site, and on LinkedIn, Indeed and other job boards.
- The [verification matrix](https://github.com/akhan157/Plainhand/blob/main/docs/VERIFICATION-MATRIX.md) now records the 1.1.1 and 1.1.2 checks, including what has not been verified yet: Workday after sign-in, and a real submission.

## Upgrading

Run the installer again. It replaces the app and keeps your workspace.

```sh
curl -fsSL https://raw.githubusercontent.com/akhan157/Plainhand/main/install.sh | sh
```

```powershell
irm https://raw.githubusercontent.com/akhan157/Plainhand/main/install.ps1 | iex
```
