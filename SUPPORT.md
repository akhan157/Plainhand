# Getting help

| What | Where |
| --- | --- |
| Installing or starting Plainhand | [Install guide](docs/INSTALL.md), including its troubleshooting table |
| How to do something | [User guide](docs/USER-GUIDE.md) |
| Something is broken | [Open a bug report](https://github.com/akhan157/plainhand/issues/new?template=bug_report.yml) |
| An idea | [Suggest a feature](https://github.com/akhan157/plainhand/issues/new?template=feature_request.yml) |
| A security problem | Report it privately, see [SECURITY.md](SECURITY.md) |

Before opening an issue, run `npm run setup -- --check` and include its
output, your operating system, Node.js version and which AI account you use.
Never paste your resume, profile or API keys into an issue.
