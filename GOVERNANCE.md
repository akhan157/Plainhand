# Governance

Plainhand is maintained by its owner, [akhan157](https://github.com/akhan157),
who decides direction, reviews pull requests and cuts releases.

- **Bug fixes and docs:** open a pull request.
- **Features and design changes:** open an issue first so we can agree on the
  approach.
- **The rules in [CONTRIBUTING.md](CONTRIBUTING.md#rules-that-dont-bend)** are
  not up for negotiation in a pull request.

Plainhand is a fork of [career-ops](https://github.com/santifer/career-ops),
which keeps its own governance. Changes to the career-ops tools that would
help everyone are best sent upstream.
